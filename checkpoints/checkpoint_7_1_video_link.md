## Summary of the presentation

The video presents a research assistant that drafts retention briefs for compensation partners on synthetic data, built on one rule: models write the words, code computes the money, and people decide. It explains the problem, the architecture and the main design decisions, then runs the system live: a costed brief that waits for sign-off, a policy comparison, a refused request and a draft with an invented figure. It closes with the evaluation, where the checks rejected 158 of 163 seeded faults and the screen refused 0 of 50 benign requests, and with the public GitHub repository.
